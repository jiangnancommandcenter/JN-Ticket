Reset project data

This permanently deletes Firestore documents. Tickets, violations, status history, chat rooms and every Area Manager / HR account. It cannot be undone — take a backup first if you are not certain.
Cloudinary files are NOT deleted. This clears Firestore documents only. Every CCTV clip, photo and PDF attached to a deleted ticket stays in Cloudinary and keeps costing storage.
Chat messages are not individually deleted. Messages, reactions, receipts, presence and profiles live inside each room and cannot be enumerated by a superadmin. Deleting the room makes them all unreachable, so every chat disappears — but the documents remain in Firestore as inert orphans.
